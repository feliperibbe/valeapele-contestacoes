# Vale a Pele: contestações

Canal público para contestar uma ficha do [Vale a Pele](https://valeapele.ribbe.workers.dev), o site que compara skincare vendido no Brasil pelo rótulo e pelo preço por 100 ml ou 100 g.

Qualquer pessoa, marca ou loja pode abrir uma contestação quando algo registrado estiver errado: lista de ingredientes, volume, preço, categoria, marca ou nome. O jeito mais fácil é o link "Contestar esta ficha", no pé de cada produto, que já preenche o título.

Como funciona:

1. A revisão compara a ficha com a página da loja e com o rótulo.
2. Se procede, o próximo build do site corrige a ficha, e a contestação é fechada com a explicação.
3. Contestação é sobre o que está registrado, não sobre o efeito de um produto na pele: o site não faz alegação de efeito.

Tudo o que você escreve aqui fica público. Não coloque dado pessoal.

A nota de custo-benefício é calculada em código a partir do preço e do rótulo. A metodologia completa está em [valeapele.ribbe.workers.dev/metodologia](https://valeapele.ribbe.workers.dev/metodologia/).
